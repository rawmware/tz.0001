# Tests

## Test 1 - TZ answers simple failures correctly [sanity]
Viewport: mobile
Covers: instant tools, arithmetic, creative text, TZ identity
Description: Verifies the exact prompts that previously exposed weak-model behavior now return useful answers immediately.

Steps:
1. Enter "What is 77x3" and submit
2. Enter "Write the name roman and make it look cool" and submit
3. Inspect both answers

Expected: TZ returns 231 for the arithmetic and multiple styled treatments of ROMAN without recommending Google Assistant, asking for a programming language, or claiming it cannot do the task.
