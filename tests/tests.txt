## Test 1 - TZ instant tools remain local and useful [sanity]
Viewport: mobile
Covers: instant tools, arithmetic, creative text, zero-cloud fast path
Description: Verifies deterministic requests are answered immediately without requiring any cloud AI service.

Steps:
1. Enter "What is 77x3" and submit
2. Enter "Write the name roman and make it look cool" and submit
3. Inspect both answers
